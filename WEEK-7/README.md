# Week 7 – SQL Query Implementation for E-Commerce Database

## Project Overview

This project focuses on implementing SQL queries for an E-Commerce Database.

The main objective is to retrieve useful information from Customer, Product, Orders, and Inventory tables using different SQL commands.

## Objectives

* Retrieve customer and product details.
* Apply filtering conditions.
* Sort records using ORDER BY.
* Retrieve unique values using DISTINCT.
* Search products using different conditions.
* Retrieve customer and product information.
* Generate basic business reports.

## SQL Concepts Used

### 1. Basic SQL Commands

* SELECT
* FROM

### 2. Filtering Conditions

* WHERE
* AND
* OR
* IN
* BETWEEN
* LIKE

### 3. Sorting

* ORDER BY ASC
* ORDER BY DESC

### 4. Unique Records

* DISTINCT

### 5. Joins

* INNER JOIN
* LEFT JOIN

### 6. Aggregate Functions

* COUNT()
* SUM()
* AVG()
* MAX()

### 7. Grouping

* GROUP BY
* HAVING

7. Highest-Priced Products
