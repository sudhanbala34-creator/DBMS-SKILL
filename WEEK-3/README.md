# Inventory Analysis – SQL

## About the Project

This project is about managing and analyzing inventory using **MySQL**.

I created two tables, **Seller** and **Inventory**, and used SQL queries to perform basic inventory operations and analysis.

## Tables Used

### Seller

* seller_id
* seller_name
* phone

### Inventory

* inventory_id
* product_name
* quantity
* price
* seller_id

The `seller_id` in the Inventory table is used to connect the inventory with the seller.

## Operations Performed

* Created the database and tables
* Inserted seller and inventory details
* Displayed the records
* Performed INSERT, SELECT, UPDATE and DELETE operations
* Found the total number of products
* Found products that are out of stock
* Found the product with the highest stock
* Calculated the average inventory quantity
* Displayed inventory details along with seller names
* Calculated total inventory quantity
* Found the highest priced product

## Tools Used

* MySQL
* MySQL Workbench

## How to Run

1. Open MySQL Workbench.
2. Copy the SQL code into the SQL Editor.
3. Execute the code.
4. Run the required `SELECT` queries separately to view the results.
5. Take screenshots of the outputs and add them to the GitHub repository.

## Conclusion

This task helped me understand how SQL can be used to create tables, manage data, perform CRUD operations, and analyze inventory using different SQL queries.
